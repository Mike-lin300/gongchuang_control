## 四、逐行讲解

### 4.1 角度 → 脉冲换算

`motor.c:12`：

```c
#define PULSE_PER_360DEG  17208u  /* 旋转标定：每度脉冲数 —— TODO 待标定！当前为占位值 360度 15800 */
```

- 含义：车身转一圈 360°，每个电机转 **17208 个脉冲**。
- 旋转函数里：`uint32_t p = deg * PULSE_PER_360DEG / 360u;`
- 90° → `90 × 17208 / 360 = 4302` 脉冲 = `0x10CE`。
- ⚠ **宏自己的注释都说 TODO 待标定**，17208 是占位值；注释里"15800"是更早的旧值，没同步。这个值必须实测（见第五节）。

> 附带一个合理性自检（我的推理，不是结论）：17208 ÷ 3200（脉冲/圈）≈ 5.38 个车轮转一圈，对应轮心走过的弧长 ≈ 5.38 × π × 78mm ≈ 1316mm；原地旋转一圈时轮心走的弧 = 2π×旋转半径，反推出旋转半径 ≈ 210mm（即轮距约 420mm），数量级和小车尺寸吻合。**但实际轮径、轮距要量，仅供你理解公式是怎么来的。**

### 4.2 顺时针函数（`shun_yaw_`，motor.c:131）

```c
void shun_yaw_(uint32_t deg)
{
    uint32_t p = deg * PULSE_PER_360DEG / 360u;                 /* ① 角度换脉冲 */
    uint8_t cmd[13] = {0x00, 0xFD, 0x00, MOTOR_SPEED_H,
        MOTOR_SPEED_L, MOTOR_ACCEL, 0,0,0,0,0, 0x01, 0x6B};     /* ② 同步位 01：先缓存 */

    cmd[6] = (uint8_t)(p >> 24);  /* ③ 脉冲填 4 字节（大端） */
    cmd[7] = (uint8_t)(p >> 16);
    cmd[8] = (uint8_t)(p >> 8);
    cmd[9] = (uint8_t)(p);

    cmd[0] = 0x01; cmd[2] = 0x00; Serial_SendArray(cmd, 13); Delay_ms(5); /* ④ FL */
    cmd[0] = 0x02; cmd[2] = 0x00; Serial_SendArray(cmd, 13); Delay_ms(5); /* ④ FR */
    cmd[0] = 0x03; cmd[2] = 0x00; Serial_SendArray(cmd, 13); Delay_ms(5); /* ④ RL */
    cmd[0] = 0x04; cmd[2] = 0x00; Serial_SendArray(cmd, 13); Delay_ms(5); /* ④ RR */

    Serial_SendByte(0x00); Serial_SendByte(0xFF);
    Serial_SendByte(0x66); Serial_SendByte(0x6B);               /* ⑤ 同步触发 */
    Delay_ms(5);
}
```

**和 02 篇的 `qianjin_()` 结构完全一样**，只有两处区别：

1. 换算公式从 `mm × 13008 / 1000` 换成 `deg × 17208 / 360`；
2. 四个轮子的方向位**全部是 0x00**（前进是 [1,0,1,0]）。

### 4.3 逆时针函数（`ni_yaw_`，motor.c:155）

逐行结构完全相同，唯一区别是四个轮子的方向位**全部是 0x01**：

```c
cmd[0] = 0x01; cmd[2] = 0x01;  /* FL */
cmd[0] = 0x02; cmd[2] = 0x01;  /* FR */
cmd[0] = 0x03; cmd[2] = 0x01;  /* RL */
cmd[0] = 0x04; cmd[2] = 0x01;  /* RR */
```

### 4.4 方向位 → 物理轮向（代码事实 + 我的推导）

按镜像映射展开：

| 函数 | 四轮方向位 [FL,FR,RL,RR] | 物理轮向（左前/右前/左后/右后） | 按标准 X 型麦轮推导 |
|---|---|---|---|
| `shun_yaw_` | 0,0,0,0 | 后退 / 前进 / 后退 / 前进（**左侧后退、右侧前进**） | 俯视应为**逆时针** |
| `ni_yaw_` | 1,1,1,1 | 前进 / 后退 / 前进 / 后退（**左侧前进、右侧后退**） | 俯视应为**顺时针** |

> 一个坦克直觉：一侧前进、另一侧后退，车就绕中心原地转。**左进右退 = 车头向右摆（顺时针）**，反之逆时针。

### 4.5 名实矛盾——已由现场反装定性（N24）

你会发现：按标准 X 型麦轮运动学推导，`shun_yaw_`（顺时针）的物理轮向反而是逆时针，`ni_yaw_`（逆时针）反而是顺时针。

代码里还有一份**实测证据**：最新提交 `aa16ae4` 的 PA8 闭环测试（main.c:264-295）里，`ni_yaw_()` 被当作"让陀螺仪角度增大"的方向，学长在注释里称之为"逆时针"，并且闭环是**稳定收敛的**（如果方向反了，闭环会越转越远、不可能收敛）。

**2026-10-16 现场结论**：根因是 FL/FR、RL/RR 四个电机反装（左右位置对调），不是陀螺仪问题也不是辊子排列问题。现场把指令地址对调后，前/后/顺/逆四个动作现象均正确，函数名与实际方向一致（笔记本 N24）。**保留现有代码，不按推导翻转**；日后换电机、重装轮子或换整车时，必须重新做一次方向核对。

### 4.6 历史：两轮旋转 → 四轮旋转

git 历史里有一次变化（`git show 8b3e4dd:app/motor.c` 可查）：

- 旧版（8b3e4dd）：旋转只发 FL、FR 两个电机，RL、RR 两行被注释掉；
- 最新版（aa16ae4）：恢复成四轮同转。

四轮同转才是标准的原地旋转（四个角都有纵向力）；只有前两轮驱动、后两轮自由滚动时，旋转中心会偏向后轴，转弯半径和脉冲都不一样。**不要把后两轮再注释回去。**

### 4.7 为什么开环转向比赛里不可靠

"发脉冲、不看角度"是开环，误差来源叠加：

1. **标定值本身是占位**（17208，注释写 TODO）；
2. 麦轮主要靠辊子摩擦，**打滑**比普通轮明显，尤其在地面接缝处；
3. 四个轮的实际直径、压紧程度不同，发相同脉冲时旋转中心会漂移；
4. 每次起步瞬间的同步误差（有同步帧，已很小但不为零）。

一次 90° 差 3°，累计 8 个阶段就会差到十几度以上——这正是 04 篇要用陀螺仪做闭环的原因。

### 4.8 另外一个没用的函数：`motor_rotate_speed`（motor.c:199）

用的是 F6 速度模式（手册第 58 页附近），按 RPM 持续转，不按脉冲定位。代码写好了但**当前没人调用**（`motor_rotate_speed_stop` 也只是它的包装）。现在先忽略；将来若需要"连续旋转直到陀螺仪到位"这种写法，它可能有用，但闭环方案里用的是位置模式（见 04 篇）。

## 五、动手验证

### 实验 1：架空车轮，串口助手直接发 `ni_yaw_(90)`

只接一个电机也行（建议先只接地址 1，看清它的转向）。悬空车架（让四轮离地），依次发：

```
01 FD 01 00 46 C8 00 00 10 CE 00 01 6B
02 FD 01 00 46 C8 00 00 10 CE 00 01 6B
03 FD 01 00 46 C8 00 00 10 CE 00 01 6B
04 FD 01 00 46 C8 00 00 10 CE 00 01 6B
00 FF 66 6B
```

（每行间隔 5ms，最后一行是同步触发。若只接了地址 1 的电机，只发第一行和同步帧即可。）

观察：

- 四个轮子应该**同时**起步、同时停；
- 左轮正转、右轮反转（从车身外侧看各轮的方向），即"一侧前进、一侧后退"。

### 实验 2：落地测真实转向（解决 4.5 的名实矛盾）

1. 车头朝向贴一块胶带做记号；
2. 发 `ni_yaw_(10)`（10°，4302÷9≈478 脉冲 = `0x01DE`，把帧里 `10 CE` 换成 `01 DE`）；
3. 看车头实际摆向哪一边、大概多少度；
4. 同样发 `shun_yaw_(10)` 对比。

把结果记到开发笔记本：**ni 实际 = 车头向左/向右；shun 实际 = 车头向左/向右**。
再和陀螺仪通电后的角度增减方向对照，就能确认是函数名反了还是陀螺仪 Z 轴反了。

### 实验 3：标定 17208（精度要求高再做）

发 `ni_yaw_(360)`（脉冲 17208 = `0x4338`），让车原地转一圈，量车头方向偏差，反复 3~5 次取平均：
`新标定值 = 17208 × 360 / 实测转过角度`。
注意：04 篇的陀螺仪闭环会在终点自动修正误差，**这个标定可以后置，不必现在做**。

2. 旋转函数里，同步帧和 `Delay_ms(5)` 能省略吗？为什么？
   <details><summary>答案</summary>
   不能。同步帧让四轮同时起步（否则排队约 25ms 起步，旋转中心会偏移）；5ms 间隔防粘包。
   </details>

3. 17208 这个值可信吗？
   <details><summary>答案</summary>
   不可信，宏注释自标 TODO 占位，15800 是更早的旧值，需实测。
   </details>

4. 为什么说"顺/逆函数名和标准推导相反"，最终怎么定性的？
   <details><summary>答案</summary>
   按镜像映射和标准 X 型麦轮推导，shun（全 0 位）物理效果为左退右进=逆时针；2026-10-16 现场查明根因是 FL/FR、RL/RR 电机反装（N24），指令地址对调后顺逆现象正确，代码按现场版本保留。
   </details>

5. 旧版只驱动前两轮，为什么要改四轮？
   <details><summary>答案</summary>
   前轮驱动+后轮自由滚动时旋转中心偏向后轴，不是原地旋转；四轮同转才是标准原地旋转。
   </details>
